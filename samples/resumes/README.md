# Sample resumes for testing

Made-up resumes (fictional people, `example.com` emails) for trying the upload
flow locally. Each one is different enough that the duplicate-resume check
won't block it when different student accounts upload them.

| File | Suggested target role |
|------|----------------------|
| `sample-software-engineer.docx` | Software Engineer |
| `sample-data-analyst.docx` | Data Analyst |
| `sample-mechanical-engineer.docx` | Mechanical Design Engineer |

Note: the portal rejects the *same* file uploaded by two different students
(duplicate-resume protection), so use a different sample per test student.
